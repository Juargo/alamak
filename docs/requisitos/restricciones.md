# Restricciones

Condiciones que no se negocian.

## Política de Riot Games

| ID | Restricción | Consecuencia |
|---|---|---|
| RES-01 | Todo producto debe registrarse en el Developer Portal y cada función nueva se audita | Registro en la semana 1 (issue #1); presentar cada función antes de lanzarla |
| RES-02 | La clave de producción exige app, prototipo, mockups o deck con el flujo | El prototipo de Figma sirve para la solicitud |
| RES-03 | Nivel gratuito obligatorio; lo pagado debe ser "transformador" y sin abusar del jugador | Gratis permanente; premium = análisis y resúmenes propios |
| RES-04 | Prohibido "dictar decisiones" | Sugerencias con alternativas, en tono reflexivo |
| RES-05 | Prohibido ser intermediario de datos | Sin anuncios basados en datos ni venta de datos |
| RES-06 | Prohibidas las calculadoras de MMR o ELO | No se estima ni se muestra MMR |
| RES-07 | Prohibido de-anonimizar o exponer Riot IDs de otros | Solo datos propios; marketing solo agregado |
| RES-08 | La IP de Riot solo desde su press kit y datos estáticos; el producto no puede parecerse a uno de Riot | Identidad visual propia; imágenes de campeones solo de Data Dragon |
| RES-09 | Aviso obligatorio de no respaldo | Texto: *"Alamak no está respaldado por Riot Games y no refleja las opiniones de Riot Games ni de nadie involucrado oficialmente en la producción o gestión de League of Legends."* |
| RES-10 | Solo datos oficiales; desde oct-2026 Riot bloquea la memoria del juego y restringe replays | Sin funciones en vivo ni replays |
| RES-24 | Las claves de desarrollo tienen límites bajos y no sirven para un producto público (verificar condiciones vigentes en el portal) | El test de tilt público necesita clave personal o de producción; ver C-17 |

## Legales y de privacidad

| ID | Restricción | Consecuencia |
|---|---|---|
| RES-11 | Ley 21.719 de Chile, vigente desde el 1-dic-2026 (multas hasta 20.000 UTM o 2–4% de ingresos si hay reincidencia) | Cumplimiento desde el primer dato recogido; seguir el proyecto de aplazamiento a 2027 |

## Recursos

| ID | Restricción | Consecuencia |
|---|---|---|
| RES-14 | Un desarrollador a tiempo parcial (~2 h/semana, ~4 h por sprint) | Alcance acotado, issues pequeños, operación simple |
| RES-15 | Presupuesto de operación ~US$60–80 al mes | Costos fijos bajos hasta ~10.000 usuarios |
| RES-16 | Sin marketing pagado hasta validar la retención | Adquisición orgánica |
| RES-17 | Comisión de la pasarela o tienda | Los precios deben absorberla. Con web, la comisión es la de la pasarela (no el 15% de las tiendas) |
