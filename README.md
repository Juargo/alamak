# Alamak

Diario de ranked en español para League of Legends. Treinta segundos después de cada partida, y cada lunes un resumen con los patrones que te están costando LP.

> Alamak no está respaldado por Riot Games y no refleja las opiniones de Riot Games ni de nadie involucrado oficialmente en la producción o gestión de League of Legends.

## Cómo se organiza el trabajo
- **Milestones** por fase: M1 Captación → M2 Pre-venta → M3 Diario → M4 Resumen semanal.
- **Sprints** de 2 semanas en el tablero de GitHub Projects.
- **Labels**: tipo (`historia`, `habilitadora`, `tarea`, `decisión`), épica, hipótesis (`H1`–`H5`), MoSCoW y talla (`talla:S/M/L`).
- Los issues siguen la plantilla *Historia o tarea* y deben poder ejecutarse sin otro contexto.

Ver `CLAUDE.md` para las reglas del producto.
